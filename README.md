# GreenGadget Hub

Create a modern, premium, responsive business website called “GreenGadget”.

Business Concept

GreenGadget is an E-Waste Buyback & Refurbishment Platform. Users can sell their old or unused electronic devices such as smartphones, laptops, tablets, smartwatches, desktops and accessories. The website estimates the device's value, allows users to book a pickup, and shows the recycling/refurbishment journey.
